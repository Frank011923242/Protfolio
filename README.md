# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and Bootstrap. This portfolio showcases a UI/UX designer's work with a dark theme and modern design elements.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern Dark Theme**: Professional dark color scheme with blue accents
- **Multiple Pages**: Separate pages for different sections
- **Interactive Elements**: Hover effects, animations, and smooth transitions
- **Portfolio Filter**: Filter projects by category (All, Website, Mobile app, Dashboard, Creatives)
- **Skills Visualization**: Animated progress bars for different skills
- **Contact Form**: Functional contact form with validation
- **Social Media Integration**: Links to social media platforms

## Pages

1. **Home (`index.html`)**: Landing page with hero section and profile introduction
2. **About (`about.html`)**: About me section with profile card and experience badges
3. **Education (`education.html`)**: Education and experience timeline
4. **Portfolio (`portfolio.html`)**: Project showcase with filtering capabilities
5. **Services (`services.html`)**: Services offered with detailed descriptions
6. **Skills (`skills.html`)**: Skills statistics and software proficiency
7. **Contact (`contact.html`)**: Contact form and contact information

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with flexbox, grid, and animations
- **Bootstrap 5**: Responsive framework and components
- **Font Awesome**: Icons and visual elements
- **JavaScript**: Interactive functionality and animations

## Getting Started

1. **Download/Clone** the project files
2. **Open** `index.html` in your web browser
3. **Navigate** through the different pages using the navigation menu
4. **Customize** the content, images, and styling to match your needs

## Customization

### Changing Content

- Update text content in each HTML file
- Replace placeholder images with your own photos
- Modify contact information in `contact.html`

### Styling

- Edit `styles.css` to change colors, fonts, and layout
- Modify the color scheme by updating CSS variables
- Adjust responsive breakpoints as needed

### Adding Projects

- Add new portfolio items in `portfolio.html`
- Update the filter categories if needed
- Ensure images are optimized for web
